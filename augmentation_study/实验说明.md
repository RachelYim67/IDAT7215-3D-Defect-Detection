# EfficientNetV2M 训练数据增强实验

目的：测量新增数据增强对缺陷识别的独立贡献，同时检验前一轮复现中发现的输入缩放问题。以下均为本组自行设计的改进实验。

## 对照设计

在三个 Study 中分别运行 2 种输入尺度 × 3 种增强策略 × 3 个优化器，共 54 个模型。保留已有的逐图划分、类别顺序、冻结的 ImageNet 主干、分类头、批大小、轮数和 0.001 学习率。每个 Study 内所有条件都从相同的分类头权重开始，采用相同的训练样本顺序和梯度更新次数。每个模型跑一个训练种子 42。训练循环采用显式的共同批次顺序，所以原缩放、无增强的对照也在本轮重新训练。

| 设置 | 实现 |
|---|---|
| original · 原缩放 | 先将输入像素除以 255，再通过模型内置预处理 |
| keras · 修正缩放 | 将 0–255 的浮点 RGB 像素直接传给模型，由内置层完成缩放 |
| none · 无新增强 | 每轮使用原训练图。Study Two 的“原训练图”指作者已发布的增强数据 |
| geometry · 几何增强 | 随机旋转 ±8°，水平和垂直平移各自不超过图像边长的 3%，双线性插值、反射填充 |
| geometry_light · 几何加光照 | 使用同一几何变换，再将相对灰度中点的对比度乘以 0.90–1.10，并加上 −12 至 +12 灰度级的亮度偏移，截断到 0–255 |

每张训练图在每套策略下用固定种子生成一张变体。每个 epoch 每张图只出现一次，以 50% 概率选变体，否则选原图。两种增强分支共用同一组采样决定。冻结的主干允许预计算这些图的特征；这种设计保证三种策略拥有同样多的训练批次。验证图和测试图均使用原图。类别 0 对应缺陷，缺陷召回率等于检出的缺陷数除以实际缺陷数。

在修正缩放的条件下，以九个“Study × 优化器”组合的验证准确率等权平均，选择一套统一策略。并列时先比较平均缺陷召回率，两项均相同时优先用较简单的策略。选择记录写入 selection.json 后，才用保存的分类头计算各个预设条件的测试预测。两种增强中的验证最优策略也单独记录，用于和无新增强做逐图配对比较。

## 重跑和复核

进入 reproduction 文件夹，使用已有 Python 环境和权重运行以下命令。

```bash
.venv/bin/python augmentation_experiment.py
.venv/bin/python summarize_augmentation.py
```

[验证集全表](validation.csv)和[测试集全表](test.csv)均保留正确数、总数、缺陷检出数和缺陷总数。[配对比较](paired_comparison.csv)中的 gained 表示加增强后由错变对的测试图片数，lost 表示由对变错的图片数。三个数据组的目录下有逐图预测、各轮训练日志、训练设置和分类头权重。

三组都沿用项目已有的图像级划分，测试集也曾用于前轮复现。此处结果反映这批留出图片的表现。Study Two 已包含作者制作的增强图像，按工件分组或换一批新工件测试，才适合评估对新工件的泛化能力。
